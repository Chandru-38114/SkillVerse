# SkillVerse

An AI-powered learning platform that helps students assess their skills, generate personalized learning roadmaps, and track their progress.

## Tech Stack

Frontend
- React
- Vite
- Tailwind CSS

Backend
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication

## Run Backend

```bash
cd backend
python -m uvicorn app.main:app --reload
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```
